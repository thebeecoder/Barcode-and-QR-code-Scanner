
# Barcode and QR Code Scanner

## Project Overview

A Python-based barcode and QR code scanner developed using computer vision techniques. The application captures real-time video through a webcam, detects and decodes barcodes and QR codes, and retrieves corresponding product information from a MySQL database.

## Key Features

- Real-time barcode and QR code detection and scanning.
- Code decoding using the Pyzbar library.
- Product information retrieval through MySQL database integration.
- Barcode generation using Python.
- Visual code detection using OpenCV.

## Technologies Used

- Python
- OpenCV
- Pyzbar
- NumPy
- MySQL
- Python Barcode Library

## Project Implementation

- Captured real-time video using a webcam.
- Processed video frames to detect and decode barcodes and QR codes.
- Connected the scanner to a MySQL database to retrieve product details, including name, company, price, manufacturing date, and expiry date.
- Implemented barcode generation functionality using Python.

## Applications

- Retail and product identification
- Inventory management
- Supply chain tracking
- Product information retrieval
